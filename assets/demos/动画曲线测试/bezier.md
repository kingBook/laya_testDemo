
三次贝塞尔曲线公式：B(t) = P₀(1−t)³ + 3P₁t(1−t)² + 3P₂t²(1−t) + P₃t³, t∈[0,1]

求导过程：
B′(t) = 3P₀(1−t)²·-1 + 3P₁[(1−t)² + 2t(1−t)·-1] + 3P₂[2t(1−t) + t²·-1] + 3P₃t²
      = -3P₀(1−t)² + 3P₁(1−t)² - 6P₁t(1−t) + 6P₂t(1−t) - 3P₂t² + 3P₃t²
      = 3(1−t)²(P₁−P₀) + 6t(1−t)(P₂−P₁) + 3t²(P₃−P₂)

一阶导数公式：B′(t) = 3(1−t)²(P₁−P₀) + 6t(1−t)(P₂−P₁) + 3t²(P₃−P₂)
